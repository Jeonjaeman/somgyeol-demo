## 구현 메모
- 스택: GSAP 3.12.5 + ScrollTrigger(cdnjs), Swiper 11.1.14(cdnjs), Pretendard 1.3.9(jsdelivr). 순수 HTML/CSS/JS, 빌드 없음.
- 핀 2구간은 `gsap.matchMedia('(min-width:769px)')` 안에서만 생성. 768 이하와 `prefers-reduced-motion`에서는 섹션 높이를 `auto`로 되돌리고 일반 등장으로 대체.
- 등장 애니메이션은 `ScrollTrigger.batch('.reveal')`. 점프 스크롤(앵커 이동·새로고침 복원) 시 한 번에 수십 개가 들어와 stagger가 길어지는 문제가 있어, 화면 밖 요소는 즉시 완료 상태로 두고 화면 안 요소만 stagger 한다.
- `[hidden]{display:none!important}`를 명시. `.modal{display:grid}`가 `hidden` 속성을 덮어써 모달이 항상 보이던 1차 QA 버그의 수정.
- 컨셉 썸네일 클릭 → `#concept`로 스크롤 후 450ms 뒤 `swiper.slideTo(idx)`. Swiper는 `autoHeight:true`로 슬라이드마다 높이가 달라도 아래 섹션을 밀지 않음.
- 갤러리는 `main.js`의 데이터 배열(제목 24, 작성자 8, 참여 수 24, 이미지 12)로 렌더. 페이지 전환은 그리드 opacity 페이드 아웃 → 교체 → 카드 stagger 등장.
- 카피 규칙 준수: em/en 대시 없음(범위 `~`), 외곽선/SVG 텍스트 없음, 의료 효능 표현 없음. 안전 안내 섹션에서 질병관리청 권고를 먼저 소개하고 "수면 중 사용을 권하지 않습니다 / 보호자가 지켜보는 깨어 있는 시간 / 뒤집기 시작 시 중단"을 굵게 표기. 같은 문장을 푸터에도 반복. KC 번호는 `CB0000-0000` 자리표시.

## 모바일(390) 단순화
- 핀 해제: 인트로·강조 섹션이 일반 밴드로. 워터마크 텍스트는 상단에 정적으로 깔림, 진행 바 숨김.
- 컨셉 썸네일 3열 → 1열(4:3 크롭), 슬라이더 2열 매거진 그리드 → 1열 스택(큰 사진 16:10 또는 1:1), 슬라이드 제목 블록 sticky 해제.
- 높이 단계 카드·수치 카드 1열, 갤러리 4열 → 2열, 콘테스트 안내 2열 → 1열(경품은 가로형 행), 리뷰 카드 1열, 안전 3열 → 1열, 푸터 정보 1열.
- 오프캔버스 메뉴 전체 폭(440px → 100%). 프로모 바의 날짜·헤더의 영문 라벨 숨김.

## 거친 부분 / 다음 단계
- 핀 구간이 끝나는 순간(인트로 3×vh의 마지막 1/3, 강조 1.5×vh의 첫 1/3) 세이지 단색만 보이는 프레임이 있다. 참고 사이트도 같은 구조이지만, 고객이 답답해하면 `end`를 `+=150%`로 줄이거나 워터마크 텍스트를 두 줄로 늘려 채울 수 있다.
- 히어로 영상은 데스크톱용 가로 1장만 사용. 모바일 세로(1080×1350) 버전이 생기면 `<source media="(max-width:768px)">`로 분기.
- 인터뷰 모달 영상은 4:3 데모 클립(`v02`)을 16:9 박스에 `object-fit:cover`로 넣었다. 실제 인터뷰 영상(16:9)으로 교체하면 `aspect-ratio` 조정.
- 갤러리 카드 비율을 4:5 / 1:1 / 4:3.2로 섞어 행마다 높이가 다르다(의도). 균일한 그리드를 원하면 `.gcard` 비율 클래스를 하나로 통일.
- 통기도 수치는 `○○ cm³/cm²/s` 자리표시. 시험성적서 수치가 나오면 `.ph-num` 교체.
- 소셜 아이콘은 범용 도형(카메라·재생·문서·말풍선)이며 특정 서비스 로고가 아니다.
